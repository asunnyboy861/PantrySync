# PantrySync 改进计划 4.0

> 目标：修复 Premium 功能限制缺失、优化首次用户体验、提升美国本地化适配，确保软件功能完整可用且符合美国用户日常使用习惯。

---

## 一、设计原则

### 1.1 需求描述 + 生成规则 + 检验标准
每个优化项必须包含：
- **需求描述**：明确要解决什么问题
- **生成规则**：代码编写规范、文件命名、接口设计
- **检验标准**：测试用例、验收条件、代码注释要求

### 1.2 功能模块原则（单一职责）
- 一个功能一个模块，高内聚低耦合
- 命名清晰，文件结构语义化
- 例如：`PremiumGate` 负责所有 Premium 限制检查，`OnboardingFlow` 负责首次引导

### 1.3 代码复用原则（最小代码原则）
- 优先复用现有模块，符合"三次法则"（遇到三次重复再抽象）
- 能合并的尽量合并，不制造冗余

### 1.4 重构清理原则
- 替换代码时先标记废弃 → 验证无影响 → 删除
- 仓库提交信息注明清理范围
- 保持代码整洁，利于后期维护

### 1.5 风格一致性原则
- 优化内容需与当前软件风格、功能、UI 保持一致
- 继承现有代码风格，不引入突兀的设计

### 1.6 兼容性原则
- 新代码必须与现有代码兼容
- 优先继承现有类/协议，而非硬编码
- 特别注意 Settings 中的配置继承关系

## 二、问题清单与优化项

### 🔴 P0 - 严重问题（必须修复）

#### 优化项 1：Premium 功能限制缺失

**需求描述**：
当前应用中的所谓 "Premium 功能" 对免费用户完全开放。Barcode 扫描、Nutrition 图表、Meal Plan、Recipe 无限添加等功能均未被限制。这会导致：
1. App Store 审核拒绝（误导性定价）
2. 用户投诉（付费后发现功能本来就能免费用）
3. 收入损失（没有付费动力）

**功能分层设计**：

| 功能 | 免费版 | Premium 版 |
|------|--------|-----------|
| Pantry 物品管理 | 最多 30 个 | 无限 |
| Grocery List | 最多 15 个 | 无限 |
| Recipes | 最多 3 个 | 无限 |
| Barcode Scanning | 不可用 | 可用 |
| Receipt Scanning | 不可用 | 可用 |
| Meal Planning | 不可用 | 可用 |
| Nutrition Charts | 不可用 | 可用 |
| iCloud Sync | 不可用 | 可用 |
| Expiration Alerts | 基础（固定3天） | 自定义天数 |

**生成规则**：

1. **新建 `PremiumFeatureGate.swift`**（Services 目录）
   - 职责：集中管理所有 Premium 功能限制检查
   - 设计为 `ObservableObject` 单例，便于 SwiftUI 响应式更新
   - 提供方法：`canUseFeature(_:)`、`currentCount(_:)`、`limitFor(_:)`

2. **新建 `PremiumFeature.swift`**（Utilities 目录）
   - 职责：定义所有 Premium 功能的枚举
   - 包含：`.barcodeScan`、`.receiptScan`、`.mealPlan`、`.nutritionCharts`、`.unlimitedPantry`、`.unlimitedGrocery`、`.unlimitedRecipes`、`.iCloudSync`、`.customAlerts`

3. **修改各 View 文件**：
   - 在功能入口处调用 `PremiumFeatureGate.shared.canUseFeature(.xxx)` 进行限制
   - 不可用时显示 Paywall 或限制提示
   - 数量限制在添加逻辑处检查

**代码编写示例**：

// Services/PremiumFeatureGate.swift
import SwiftUI
import SwiftData

@MainActor
@Observable
final class PremiumFeatureGate {
    static let shared = PremiumFeatureGate()
    
    private var purchaseManager: PurchaseManager { PurchaseManager.shared }
    
    private init() {}
    
    /// 检查用户是否可以使用某功能
    func canUseFeature(_ feature: PremiumFeature) -> Bool {
        if purchaseManager.isPremium { return true }
        
        switch feature {
        case .barcodeScan, .receiptScan, .mealPlan, .nutritionCharts, .iCloudSync, .customAlerts:
            return false
        case .unlimitedPantry, .unlimitedGrocery, .unlimitedRecipes:
            return true // 数量限制在别处检查
        }
    }
    
    /// 检查是否达到数量限制
    func isUnderLimit(_ feature: PremiumFeature, currentCount: Int) -> Bool {
        if purchaseManager.isPremium { return true }
        guard let limit = feature.freeLimit else { return true }
        return currentCount < limit
    }
    
    /// 获取限制提示文本
    func limitMessage(for feature: PremiumFeature) -> String? {
        if purchaseManager.isPremium { return nil }
        guard let limit = feature.freeLimit else { return nil }
        return "Free limit: \(limit) items. Upgrade to Premium for unlimited access."
    }
}

#### 优化项 2：首次启动引导（Onboarding）

**需求描述**：
当前应用首次启动显示空状态页面，没有引导教程或示例数据。美国用户期望首次启动时有引导教程、示例数据或功能介绍。

**生成规则**：

   - 使用 `@AppStorage` 管理首次启动状态
   - 提供 `hasCompletedOnboarding` 属性
   - 提供 `completeOnboarding()` 方法

2. **新建 `OnboardingView.swift`**（Views/Onboarding 目录）
   - 3-4 页引导页：欢迎、功能介绍、Premium 说明、开始
   - 支持滑动切换和跳过
   - 最后一页提供 "Load Sample Data" 和 "Start Fresh" 选项

3. **修改 `PantrySyncApp.swift`**：
   - 根据 `hasCompletedOnboarding` 决定显示 `OnboardingView` 还是 `ContentView`

4. **复用现有 `ScreenshotDataSeeder`**：
   - 在 Onboarding 最后一页调用 `ScreenshotDataSeeder.seed()`

**代码编写示例**：

// Services/OnboardingManager.swift

**需求描述**：
当前使用 OpenFoodFacts API，在美国的产品覆盖率不如欧洲。建议添加备用数据源或优化美国商品识别。

**生成规则**：

   - 添加 HTTPS 支持（当前可能是 HTTP）
   - 添加错误处理和重试机制

2. **新建 `BarcodeCache.swift`**：
   - 缓存已查询过的 barcode 结果
   - 减少 API 调用，提升离线体验

**代码编写示例**：

```swift
// Services/BarcodeCache.swift
import Foundation

actor BarcodeCache {
    static let shared = BarcodeCache()
    
    private var cache: [String: BarcodeProduct] = [:]
    private let cacheKey = "barcode_cache"
    
    private init() {
        // 从 UserDefaults 加载缓存
        if let data = UserDefaults.standard.data(forKey: cacheKey),
           let decoded = try? JSONDecoder().decode([String: BarcodeProduct].self, from: data) {
            cache = decoded
        }
    }
    
    func get(_ barcode: String) -> BarcodeProduct? {
        cache[barcode]
    }
    
    func set(_ product: BarcodeProduct, for barcode: String) {
        cache[barcode] = product
        save()
    }
    
    private func save() {
        if let data = try? JSONEncoder().encode(cache) {
            UserDefaults.standard.set(data, forKey: cacheKey)
        }
    }
}
```

**检验标准**：
- [ ] Barcode 查询使用 HTTPS
- [ ] 查询结果缓存到本地
- [ ] 重复查询相同 barcode 时从缓存读取
