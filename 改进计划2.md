# PantrySync 改进计划 2

## 📋 概述

本文档基于深度检查结果，规划 PantrySync 应用的进一步优化方案。所有优化遵循以下原则：
1. 需求描述 + 生成规则 + 检验标准
2. 功能模块原则（单一职责，高内聚低耦合）
3. 代码复用原则（优先复用，三次法则）
4. 代码清理原则（重构清理，标记废弃）
5. 风格一致性原则（格调、功能、UI一致）
6. 继承兼容性原则（优先继承，避免硬编码）

---

## 🔍 问题分析

### 问题 1: iCloud 同步未真正实现 🟡 中优先级

**现状**：
- 设置中有"Enable iCloud Sync"开关
- `AppStorage("useCloudKit")` 只保存布尔值
- `ModelConfiguration` 未配置 CloudKit
- 开关无实际效果，造成用户困惑

**影响**：
- 用户误以为数据已同步
- 换设备后数据丢失
- 影响应用可信度

---

### 问题 2: 缺少编辑功能 🟡 中优先级

**现状**：
- 用户添加食品/购物清单/食谱后无法修改
- 只能删除后重新添加
- 影响用户体验

**影响**：
- 用户操作繁琐
- 数据丢失风险
- 用户满意度降低

---

## 📐 优化方案

### 方案 1: 实现 iCloud 同步功能

#### 需求描述

实现真正的 iCloud 同步功能，允许用户在多个设备之间同步数据。用户已配置 `iCloud.com.zzoutuo.PantrySync`，需要在代码中正确配置 CloudKit。

#### 生成规则

1. **配置 ModelConfiguration**：在 `PantrySyncApp.swift` 中配置 CloudKit
2. **使用 AppStorage 开关**：根据用户设置决定是否启用 iCloud 同步
3. **处理同步状态**：添加同步状态指示器

#### 检验标准

**代码编写示例**：
```swift
// ✅ 实现后
@main
struct PantrySyncApp: App {
    @AppStorage("useCloudKit") private var useCloudKit = false
    
    var sharedModelContainer: ModelContainer = {
        let schema = Schema([
            PantryItem.self, GroceryItem.self, Recipe.self,
            MealPlan.self, DailyNutritionLog.self
        ])
        
        let config: ModelConfiguration
        if useCloudKit {
            // 启用 iCloud 同步
            config = ModelConfiguration(
                schema: schema,
                isStoredInMemoryOnly: false,
                cloudKitDatabase: .automatic
            )
        } else {
            // 仅本地存储
            config = ModelConfiguration(
                schema: schema,
                isStoredInMemoryOnly: false
            )
        }
        
        do {
            return try ModelContainer(for: schema, configurations: [config])
        } catch {
            fatalError("Could not create ModelContainer: \(error)")
        }
    }()

    var body: some Scene {
        WindowGroup {
            ContentView()
        }
        .modelContainer(sharedModelContainer)
    }
}
```

### 方案 2: 添加食品编辑功能

#### 需求描述

为 `PantryItem` 添加编辑功能，允许用户修改已添加的食品信息。

#### 生成规则

1. **创建 EditPantryItemView**：复用 `AddPantryItemView` 的 UI 结构
2. **添加编辑入口**：在 `PantryItemRow` 上添加点击事件
3. **预填充数据**：编辑时显示现有数据
4. **保存修改**：更新现有记录而非创建新记录

#### 检验标准

**代码编写示例**：

```swift
// MARK: - EditPantryItemView.swift
// 文件位置: Views/Pantry/EditPantryItemView.swift

import SwiftUI
import SwiftData

struct EditPantryItemView: View {
    @Environment(\.modelContext) private var modelContext
    @Environment(\.dismiss) private var dismiss
    
    let item: PantryItem  // 接收要编辑的食品
    
    @State private var name: String
    @State private var category: String
    @State private var storageLocation: String
    @State private var quantity: Double
    @State private var unit: String
    @State private var expirationDate: Date
    @State private var hasExpirationDate: Bool
    @State private var price: String
    
    // 初始化时预填充现有数据
    init(item: PantryItem) {
        self.item = item
        _name = State(initialValue: item.name)
        _category = State(initialValue: item.category)
        _storageLocation = State(initialValue: item.storageLocation)
        _quantity = State(initialValue: item.quantity)
        _unit = State(initialValue: item.unit)
        _expirationDate = State(initialValue: item.expirationDate ?? Date().addingTimeInterval(7 * 86400))
        _hasExpirationDate = State(initialValue: item.expirationDate != nil)
        _price = State(initialValue: item.price != nil ? String(item.price!) : "")
    }
    
    var body: some View {
        NavigationStack {
            Form {
                // 复用 AddPantryItemView 的 UI 结构
                Section("Item Details") {
                    TextField("Item name", text: $name)
                    Picker("Category", selection: $category) {
                        ForEach(FoodCategory.allCases) { cat in
                            Text(cat.rawValue).tag(cat.rawValue)
                        }
                    }
                    Picker("Location", selection: $storageLocation) {
                        ForEach(StorageLocation.allCases) { loc in
                            Text(loc.rawValue).tag(loc.rawValue)
                        }
                    }
                }
                
                Section("Quantity") {
                    HStack {
                        TextField("Amount", value: $quantity, format: .number)
                            .keyboardType(.decimalPad)
                        Picker("Unit", selection: $unit) {
                            ForEach(QuantityUnit.allCases) { u in
                                Text(u.rawValue).tag(u.rawValue)
                            }
                        }
                    }
                }
                
                Section("Details") {
                    Toggle("Has expiration date", isOn: $hasExpirationDate)
                    if hasExpirationDate {
                        DatePicker("Expires", selection: $expirationDate, displayedComponents: .date)
                    }
                    TextField("Price", text: $price)
                        .keyboardType(.decimalPad)
                }
            }
            .navigationTitle("Edit Item")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("Cancel") { dismiss() }
                }
                ToolbarItem(placement: .confirmationAction) {
                    Button("Save") {
                        saveChanges()
                    }
                    .disabled(name.isEmpty)
                }
            }
        }
    }
    
    private func saveChanges() {
        // 更新现有记录
        item.name = name
        item.category = category
        item.storageLocation = storageLocation
        item.quantity = quantity
        item.unit = unit
        
        if hasExpirationDate {
            item.expirationDate = expirationDate
            // 更新过期提醒
            NotificationService.cancelAlert(id: item.id.uuidString)
            NotificationService.scheduleExpirationAlert(
                for: name,
                expirationDate: expirationDate,
                id: item.id.uuidString
            )
        } else {
            item.expirationDate = nil
            NotificationService.cancelAlert(id: item.id.uuidString)
        }
        
        if let priceValue = Double(price) {
            item.price = priceValue
        }
        
        item.updatedAt = Date()
        try? modelContext.save()
        dismiss()
    }
}
```

import SwiftUI

struct PantryItemRow: View {
    let item: PantryItem
    
    var body: some View {
        HStack(spacing: 12) {
            Image(systemName: iconForCategory(item.category))
                .font(.title3)
                .foregroundStyle(colorForCategory(item.category))
                .frame(width: 32)
            
            VStack(alignment: .leading, spacing: 2) {
                Text(item.name)
                    .font(.subheadline.weight(.medium))
                HStack(spacing: 8) {
                    Text("\(item.quantity.formatted()) \(item.unit)")
                        .font(.caption)
                        .foregroundStyle(.secondary)
                    Text(item.storageLocation)
                        .font(.caption2)
                        .foregroundStyle(.secondary)
                }
            }
            
            Spacer()
            
            ExpiryBadge(daysLeft: item.daysUntilExpiration)
        }
        .padding(.vertical, 4)
    }
    
    private func iconForCategory(_ category: String) -> String {
        FoodCategory(rawValue: category)?.icon ?? "square.grid.2x2.fill"
    }
    
    private func colorForCategory(_ category: String) -> Color {
        switch category {
        case "Produce": return .green
        case "Dairy": return .blue
        case "Meat & Seafood": return .red
        case "Grains & Bread": return .orange
        case "Frozen": return .cyan
        case "Canned & Jarred": return .brown
        case "Snacks": return .yellow
        case "Beverages": return .teal
        case "Condiments & Spices": return .indigo
        case "Baking": return .pink
        case "Household": return .gray
        default: return .secondary
        }
    }
}

## 🔧 App Store 审核问题修复

### 问题描述

**错误信息**: ITMS-90683: Missing purpose string in Info.plist

**原因**: 应用使用了相机 API（用于条形码扫描），但 Info.plist 中缺少 `NSCameraUsageDescription` 键。

### 修复方案

在项目配置文件 `project.pbxproj` 中添加隐私权限描述：

**修改文件**: `PantrySync.xcodeproj/project.pbxproj`

**添加的配置**:
```
INFOPLIST_KEY_NSCameraUsageDescription = "PantrySync needs access to your camera to scan barcodes and receipts for easy item entry.";
INFOPLIST_KEY_NSMicrophoneUsageDescription = "PantrySync does not use the microphone, but this permission is required for camera functionality.";
INFOPLIST_KEY_NSPhotoLibraryUsageDescription = "PantrySync needs access to your photo library to add photos to your recipes and pantry items.";
```

### 隐私权限说明

| 权限 | 用途 | 说明 |
|------|------|------|
| **NSCameraUsageDescription** | 条形码扫描 | 用于扫描食品条形码和收据 |
| **NSMicrophoneUsageDescription** | 相机功能 | iOS 要求使用相机时必须声明麦克风权限 |
| **NSPhotoLibraryUsageDescription** | 添加照片 | 用于为食谱和食品添加照片 |
